# Coding Standards

-   **JavaScript**: strict usage for both frontend and backend.
-   camelCase for variables/functions.
-   PascalCase for React components/classes where appropriate.
-   Descriptive names; avoid abbreviations unless universally understood.
-   Use `.js` and `.jsx`.

-   **Python**: snake_case for modules/functions/variables.
-   PascalCase for classes.
-   Type hints required for public functions.

File names must describe purpose. Avoid `helper.js`, `misc.js`, `common.js`, `temp.js`, `manager.js`.
